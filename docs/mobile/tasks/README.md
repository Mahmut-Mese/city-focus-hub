# Mobile Task Files

The full task chain lives in `docs/mobile/CHAIN.md`.

Use this directory for expanded one-off task briefs when a task needs more context than the chain row provides.

Rules:

- File name format: `TXXX-short-name.md`.
- Include the task row, relevant contracts, and exact output files.
- Do not duplicate broad project context; reference `AGENT_RUNTIME.md`.
- If a task file changes a contract, update `CONTRACTS.md` first.
